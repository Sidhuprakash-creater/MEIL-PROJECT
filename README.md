# MEIL ESG & BRSR — Enterprise Portal

Enterprise ESG (Environmental, Social, and Governance) & BRSR Reporting Workspace for Megha Engineering & Infrastructures Limited (MEIL).

## Features
- **Group Admin & Unit Workspaces**: Multi-tier hierarchy across Subsidiaries, Business Units, and Projects.
- **BRSR Core & Analytics**: 9-step guided BRSR filing wizard, automated consolidation, anomaly detection, and ESG KPI dashboards.
- **Submissions & Review Workflow**: Multi-stage review, approval, sign-offs, and immutable audit logs.
- **Liquid-Glass UI**: High-fidelity dashboard interface with interactive charts and real-time status tracking.

## Tech Stack
- Next.js 16 (App Router)
- React 19 + TypeScript
- Tailwind CSS
- Prisma ORM + SQLite
- Framer Motion + Recharts + Zustand

## Getting Started
```bash
npm install
npm run db:push
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) or configured port in your browser.
